## Flying Scotsman 3D

`flying-scotsman/index.html` is an interactive 3D model of LNER Class A3 No. 4472/60103 *Flying Scotsman*, built with Three.js. Open the file in a browser (it loads Three.js and fonts from a CDN).

- Orbit, zoom and jump between camera views (lineside, head-on, wheels, driver's view, bird's eye)
- Drive it: regulator, brake, whistle and a fire to keep stoked, with a 60x-speed run from King's Cross to Edinburgh
- Switch between today's BR green (60103) and the 1928 LNER apple green (4472)
- Tap the brass hotspots for facts written for children and for engineers, read the history timeline, take the quiz and collect badges
